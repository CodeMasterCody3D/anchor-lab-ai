# /researchpaper — Academic Research Paper Generator

When the user runs `/researchpaper`:

1. Run the paper generator:
   ```bash
   anchor-lab-ai paper
   ```
2. Present the paper structure:
   - **Title & Abstract**
   - **Q-TKintergers Base-3 Formulation** (zero-float integer affine anchors)
   - **Distributed Compute Setup** (Colab A100, Kaggle Cloud, Desktop Rig 192.168.1.80)
   - **Empirical Benchmarks** (Wikitext-2 PPL tables: 8-bit reference 9.94754 vs 1-bit 11.58607)
   - **Failure Analysis** (from isolated graveyard)
3. Provide the file path to the generated paper:
   `~/.anchor-lab-ai/projects/quantization-side-lab/papers/RESEARCH_PAPER.md`
